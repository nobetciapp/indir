# Nöbetçi — kurulum dosyaları

Bu depo yalnızca **Nöbetçi kurulum dosyalarını** barındırır; kaynak kodu içermez.

En son sürümü **[Sürümler (Releases)](../../releases/latest)** sayfasından indirebilirsiniz:

| Dosya | Bilgisayar |
|---|---|
| `Nobetci-windows.zip` | Windows 10/11 (64 bit) |
| `Nobetci-mac-arm64.tar.gz` | Mac — Apple Silicon (M1, M2, M3 …) |
| `Nobetci-mac-x64.tar.gz` | Mac — Intel |

**Windows:** zip'i bir klasöre çıkarın, `Nöbetçi\Nöbetçi.exe`'ye çift tıklayın. İlk açılışta "Windows bilgisayarınızı korudu" uyarısı çıkarsa **Ek bilgi → Yine de çalıştır**.

**Mac:** `Nöbetçi.app`'i Uygulamalar klasörüne sürükleyin. İlk açılışta uyarı çıkarsa uygulamaya sağ tıklayıp **Aç** deyin.

Verileriniz yalnızca kendi bilgisayarınızda, şifreli olarak saklanır.
